Testing the limits of DemoDiffusion.

This animation needs WebGL. The steps below tell the same story.

Task: robot puts bowl in sink.

A person shows it once.

Next time, the bowl moves.

Copying the demo exactly would miss the bowl.

We add noise to the demo.

The robot cleans it up to fit.

The bowl goes in the sink.
