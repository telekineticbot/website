An exploration on exploration

Proposal for safe real world robot exploration.

Vineeth YeevaniVrishabh KenkreNovember 18, 2026

This animation needs WebGL. The steps below tell the same story.

We want robots that improve themselves.

Give it a task it can't solve yet.

It has to explore to find a way.

Most methods wiggle around and pray.1

Wiggling rarely finds anything new.

Ours: blindfold it and give it the rough plan.

It fills in realistic motion on its own.

Many new tries. One works.

Who carries the spread

A generative model learns many modes only when its input leaves room for them. Most tools for modeling many modes come from image and video generation. There a short prompt conditions a large image, so the image has to carry the spread.

A robot policy runs the other way. A large state, its camera images and joint readings, conditions a short action. The state can carry all of the spread.

Every state is seen once

No two robot states are exactly alike, so each training state comes with exactly one action . On the training data the state decides the action completely:

All the spread in the actions is explained by the state, and none is left for to model.

The data adds little spread of its own. Fine-tuning data for "should exhibit a consistent and fluent strategy",2 and more consistent demos train better policies.3456

So the policy becomes a look-up table

Flow matching, which and use,215 mixes an action with noise and learns the velocity back to the action:

The best velocity averages over every training action that fits and . With one action per state that is only , so every path runs straight to it:

The loss reaches zero with a fixed map from state to action. Nothing rewards probability on any other action, so the model never has to learn several modes. This holds for the pretrained VLA and for fine-tuning alike.

This is about the loss at its optimum for a model expressive enough to reach it, so a smaller network or its biases could leave some spread.

Studies of fine-tuned VLAs see this look-up table behavior.8910121314 Across nine VLAs on LIBERO, "the actions of the VLAs remain close to the demonstrations".11

A look-up table can't explore

At a new state the model's move comes from interpolating the table between nearby training states. When it misses the grasp that works, , the gap is the same on every try. Sampling the policy again gives the same miss.
