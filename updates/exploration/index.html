An exploration on exploration

Proposal for safe real world robot exploration.

This animation needs WebGL. The steps below tell the same story.

We want robots that improve themselves.

Give it a task it can't solve yet.

It has to explore to find a way.

Most methods wiggle around and pray.1

Wiggling rarely finds anything new.

Ours: blindfold it and give it the rough plan.

It fills in realistic motion on its own.

Many new tries. One works.

The data shows one way

Robot data is collected so policies learn easily, which means one consistent way to do each task. 's fine-tuning data "should exhibit a consistent and fluent strategy".2 Studies find that more consistent demos train better policies.3456

Big datasets add variety in scenes and tasks. DROID is built that way; we found nothing in it that asks for different ways to do one task.7

So the policy learns one move per scene

No two camera images are alike, so in the data each scene comes with exactly one action. The policy learns as a narrow spike. It only spreads where scenes it sees as alike were done differently.

Fine-tuning pushes it toward a look-up table from scene to move.8910121314 Across nine VLAs on LIBERO, "the actions of the VLAs remain close to the demonstrations".11
